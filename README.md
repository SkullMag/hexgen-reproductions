# HexGen reproductions

This repository collects the code, protocols, and results for reproducing the HexGen papers.

| Directory | Contents |
| --- | --- |
| [hexgen1](hexgen1/) | HexGen source and FABRIC reproduction tools |
| [hexgen2](hexgen2/) | HexGen‑2 source, the October UTAH comparison, and the November CERN GPUDirect pilot |
| [hexgen3](hexgen3/) | Directory reserved for the HexGen‑3 reproduction |

Each version keeps a pinned source snapshot in `source/` and cross-system benchmarks live under the newer system’s `experiments/` directory. The published forks retain their original history, pull requests, and release assets. The version READMEs record the exact import commits.

Store code, protocols, small result files, and figures in Git. Keep model weights, GPU environment binaries, credentials, raw infrastructure inventories, and large telemetry archives outside this repository.
